# ADR 001: 将 MTD 刷写集成到工具箱

- 状态：已接受
- 日期：2026-09-21

## 背景

原项目通过 Lua 和批处理固定执行 mtd4 备份、刷写、校验和重启。WiFitool 已经提供统一的 ADB、外部工具执行和日志能力，需要把它收敛成一个工具箱内的小工具。

## 决策

- 工具箱名称使用“MTD刷写”。
- 固件通过统一风格的弹窗选择，选择后显示警告并直接执行完整流程。
- 使用 WiFitool 当前在线 ADB 设备，不增加第二套设备选择器。
- 备份保存到所选固件同目录的 `mtd4_bak.bin`，同名文件直接覆盖。
- 复用 `AdbService`、`ToolRunner` 和 `LogService`。
- 刷写成功后执行校验、清理临时文件并自动重启；中途失败立即停止且不自动重启。
- 仅集成 `MTDWriter` 和 `MTDChecker` 两个设备端工具，不保留 Lua、批处理和控制台界面。

## 后果

- 工具实现保持在一个刷写服务和一个工具箱弹窗内。
- 详细过程进入 WiFitool 统一日志，界面只显示当前步骤。
- 该操作会覆盖设备 `/dev/mtd4`，弹窗警告仍是必要的唯一确认步骤。
